### Data Science | Machine Learning | Python  
Engenheira de Produção em transição para Ciência de Dados, com foco em Análise de Dados, Estatística Aplicada e Machine Learning. 
Desenvolvo projetos end-to-end, desde extração e tratamento de dados (ETL) até modelagem e interpretação de resultados.

🧠 Foco em Data Science
  - Análise Exploratória de Dados (EDA)
  - Estatística Aplicada
  - Machine Learning Não Supervisionado: Clustering (Hierárquico, K-Means) e Análise de Correspondência Múltipla (ACM)
  - Identificação de padrões, outliers e segmentação de dados
  - Avaliação e comparação de modelo

⚙️ Base em Engenharia de Dados
  - ETL e Data Cleaning
  - Construção de pipelines reprodutíveis
  - SQL e MySQL
  - Apache Airflow (DAGs)
  - Versionamento com Git

🛠 Stack Técnica:
  - **Python:** Pandas, NumPy, SciPy, Scikit-Learn, Plotly, Prince
  - **Banco de Dados:** SQL, MySQL, SQLAlchemy
  - **Engenharia de Dados:** ETL, Airflow
  - **Ambiente:** Linux (WSL2 / Ubuntu), Conda, Git
